## Κολοφώνας

Η σελίδα είναι στατική: χτίζεται με το [Eleventy](https://www.11ty.dev/) από αρχεία Markdown και δημοσιεύεται στο GitHub Pages μέσω GitHub Actions. Δεν φορτώνει τίποτα από τρίτους — ούτε γραμματοσειρές, ούτε scripts, ούτε ιχνηλάτες. Ο [κώδικας](https://github.com/ffeizidis/ffeizidis.github.io) είναι ανοιχτός.

Τα στοιχεία είναι [EB Garamond](https://github.com/octaviopardo/EBGaramond12), η αναβίωση των τύπων του Claude Garamont από τον Georg Duffner, με τα ελληνικά του Octavio Pardo· μεταβλητή γραμματοσειρά, όρθια και πλάγια, φιλοξενούμενη εδώ. Οι υποσημειώσεις στοιχειοθετούνται ως σημειώσεις στο περιθώριο. Οι τυπογραφικοί κανόνες ακολουθούν το [Practical Typography](https://practicaltypography.com/) του Matthew Butterick.
