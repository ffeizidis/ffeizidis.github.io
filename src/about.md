## Κολοφώνας

Η σελίδα είναι στατική· χτίζεται με το [Eleventy](https://www.11ty.dev/) από αρχεία Markdown και δημοσιεύεται στο GitHub Pages μέσω GitHub Actions.

Τα στοιχεία είναι [EB Garamond](https://github.com/octaviopardo/EBGaramond12), η αναβίωση των τύπων του Claude Garamont από τον Georg Duffner, με τα ελληνικά του Octavio Pardo. Οι τυπογραφικοί κανόνες ακολουθούν το [Practical Typography](https://practicaltypography.com/) του Matthew Butterick.
